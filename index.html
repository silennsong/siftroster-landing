Frequently Asked Questions

How do I connect my own AI Agent (Claude, Cursor, custom agents) to SiftRoster?

Every workspace includes an authenticated Model Context Protocol (MCP) server endpoint and REST API key. Plug SiftRoster into your Agent client to schedule sourcing runs, refine creator persona filters, fetch confidence-scored emails, and stage personalized drafts via natural conversation—no repetitive UI clicking required.

Do I still get a Web SaaS interface for human review and retrospectives?

Yes. SiftRoster intentionally pairs Agent execution with a clean Human-in-the-Loop Web Workbench. Instead of micromanaging every filter, you open the Web UI only at critical checkpoints: batch shortlists, email evidence inspection, draft sign-off, and post-campaign retrospectives.

How is SiftRoster different from generic influencer databases?

Static creator databases rely on outdated scrapes and vanity follower counts. SiftRoster runs fresh discovery per brief, checks recent non-pinned video medians, evaluates actual video context against your client persona, and verifies contact confidence with source evidence.

Can I run multiple client campaigns or agent workflows on one account?

Yes. Boutique Agency and Scale Agency tiers separate persona rules, candidate pools, MCP/API credentials, and outreach suppression lists by client workspace—while protecting against duplicate pitches across YouTube and TikTok.
